# AirSense --- REST API Reference (`/api/v1`)

All API routes return JSON and standard HTTP status codes.

---

## 1. Authentication

### `POST /api/v1/auth/register`
Create a new user account.
- **Request Body:**
  ```json
  {
    "name": "Jane Citizen",
    "email": "jane@example.com",
    "password": "securepassword123"
  }
  ```
- **Response (201 Created):**
  ```json
  {
    "message": "User registered successfully",
    "token": "<JWT_TOKEN>",
    "user": { "id": 1, "name": "Jane Citizen", "email": "jane@example.com" }
  }
  ```

### `POST /api/v1/auth/login`
Authenticate existing user.
- **Request Body:**
  ```json
  {
    "email": "jane@example.com",
    "password": "securepassword123"
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "message": "Login successful",
    "token": "<JWT_TOKEN>",
    "user": { "id": 1, "name": "Jane Citizen", "email": "jane@example.com" }
  }
  ```

### `GET /api/v1/auth/me`
Retrieve currently authenticated profile.
- **Headers:** `Authorization: Bearer <JWT_TOKEN>`
- **Response (200 OK):**
  ```json
  {
    "user": { "id": 1, "name": "Jane Citizen", "email": "jane@example.com" }
  }
  ```

## 2. Locations

### `GET /api/v1/locations`
List or search supported cities and regions.
- **Query Parameters:** `search` (optional string)
- **Response (200 OK):**
  ```json
  {
    "locations": [
      {
        "id": 1,
        "name": "Delhi",
        "region": "Delhi",
        "country": "India",
        "latitude": 28.6139,
        "longitude": 77.2090
      }
    ]
  }
  ```

### `POST /api/v1/locations`
Add a new monitoring location.
- **Request Body:**
  ```json
  {
    "name": "Jaipur",
    "region": "Rajasthan",
    "country": "India",
    "latitude": 26.9124,
    "longitude": 75.7873
  }
  ```

## 3. Air Quality Data

### `GET /api/v1/air-quality/current`
Retrieve latest observation for a specific location. Triggers on-demand provider fetch if database is empty.
- **Query Parameters:** `location_id` (required int)
- **Response (200 OK):**
  ```json
  {
    "location": { "id": 1, "name": "Delhi" },
    "reading": {
      "aqi_value": 182.0,
      "aqi_standard": "IN_CPCB",
      "pm25": 84.5,
      "pm10": 165.2,
      "no2": 45.1,
      "so2": 18.3,
      "co": 1100.0,
      "o3": 62.0,
      "observed_at": "2026-11-08T18:00:00"
    },
    "aqi_summary": {
      "value": 182.0,
      "standard": "IN_CPCB",
      "category": "Moderate",
      "color": "#FFFF00",
      "label": "Breathing discomfort to people with lungs, asthma and heart diseases."
    },
    "freshness": {
      "is_stale": false,
      "observation_age_hours": 0.5,
      "observed_at": "2026-11-08T18:00:00",
      "last_successful_update": "2026-11-08T18:05:00"
    },
    "provenance": {
      "provider": "open_meteo",
      "measurement_type": "modelled"
    }
  }
  ```

### `GET /api/v1/air-quality/history`
Retrieve historical hourly observations.
- **Query Parameters:** `location_id` (required int), `days` (optional int, default 7, max 30)

## 4. Forecasting

### `GET /api/v1/forecasts`
Retrieve 24-hour ahead hourly PM2.5 forecasts generated by the Random Forest model.
- **Query Parameters:** `location_id` (required int)
- **Response (200 OK):**
  ```json
  {
    "status": "available",
    "model_name": "RandomForestRegressor",
    "model_version": "1.0.0",
    "count": 24,
    "evaluation_summary": {
      "random_forest": { "test_mae": 38.14, "test_rmse": 49.17 },
      "persistence_baseline": { "test_mae": 25.49, "test_rmse": 32.91 }
    },
    "forecasts": [
      {
        "forecast_for": "2026-11-09T00:00:00",
        "target_metric": "pm25",
        "predicted_value": 78.4,
        "unit": "µg/m³",
        "horizon_hours": 1
      }
    ]
  }
  ```

## 5. Alerts & Notifications

- `GET /api/v1/alerts`: List user's active AQI alert thresholds.
- `POST /api/v1/alerts`: Create alert preference (`location_id`, `threshold_value`, `enabled`).
- `PATCH /api/v1/alerts/<id>`: Update alert preference.
- `DELETE /api/v1/alerts/<id>`: Delete alert preference.
- `GET /api/v1/notifications`: List recent notifications.
- `PATCH /api/v1/notifications/<id>/read`: Mark notification as read.

---

## 6. Health & Metrics

- `GET /api/v1/health/live`: Liveness check (200 OK).
- `GET /api/v1/health/ready`: Readiness check verifying MySQL database connectivity (200 OK / 503 Service Unavailable).
- `GET /metrics`: Prometheus formatted operational metrics.
